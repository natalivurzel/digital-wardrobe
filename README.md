# Wardrobe v2

## Обновление GitHub Pages
1. Распакуйте архив.
2. В репозитории `digital-wardrobe` откройте Add file → Upload files.
3. Загрузите файлы из архива в корень репозитория и подтвердите Commit changes. При запросе подтвердите замену существующих файлов.
4. Подождите завершения GitHub Pages и откройте сайт заново. Если старая версия осталась в кэше, закройте вкладку, откройте сайт ещё раз или обновите страницу с очисткой кэша.

## Новое
- отдельный Wishlist;
- добавление вещей из гардероба и Wishlist в один коллаж;
- управление коллажем: одним пальцем перемещение, двумя пальцами масштабирование и поворот;
- удаление вещей через карточку → «Открыть» → «Удалить вещь»;
- категории и базовые подкатегории;
- экспорт/импорт гардероба, Wishlist, фотографий и сохранённых образов.

## Удаление фона
В карточке вещи нажмите «Открыть» → «Удалить фон». При первом запуске браузер загружает AI-модель из CDN. Обработка выполняется в браузере, но для загрузки модели требуется интернет. Функция экспериментальная: результат зависит от снимка, а библиотека/модель может быть тяжёлой для некоторых телефонов. Оригинальная фотография остаётся сохранённой.

## Хранение
Данные остаются в IndexedDB браузера на устройстве. GitHub хранит только код приложения. Экспортируйте резервную копию регулярно, особенно перед очисткой данных браузера или переносом на другое устройство.
